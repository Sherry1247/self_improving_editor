# 违例集 v3（匹配对照）上的结果：EditReward vs 我们的 critics（2026-11-06）

数据：CHTC `e1v3`（critics，15 张源图 × 11 种变体 = 165 项）、`rw_v3_er`（EditReward，165 项无空值）。
完整表：CHTC `runs/vio_er/compare.md|csv`（`experiments/violation_compare.py` 生成）。
AUROC [95% CI，按 15 张源图 cluster bootstrap 2000 次]。**VIEScore 这一轮无效**：任务没带 `--soft`，整数版几乎全打平
（日志里大多数项都是 0.8485），软分数文件为空，需要重跑，见文末。

## 这一版违例集改了什么
- 所有变体（含干净粘贴 null）共用同一块补背景区域（union of masks），涂抹量在 null / float / sink / shift_side*
  上一致（0.41）；scale_down 0.71、scale_up 0.29 **没有**对齐。
- 新增良性对照 `shift_side` / `shift_side_s`（水平平移，位移量 = float / sink，脚下一条地面随主体一起移动）。
- 三类读法：detect = null vs 违例；benign = null vs 平移（应 ≈0.5）；contrast = 平移 vs 悬空 / 下沉（同位移，只差接触）。

## 读法
1. **匹配对照把 EditReward 的数字压下来了。** 旧违例集上 0.75–0.99（7 类全部 CI 下界 >0.5），现在 0.47–0.88。
   下沉（sink）0.47 未检出；悬空 0.68，但悬空 vs 平移的 contrast 只有 0.63 [.46,.79]，CI 跨 0.5，不能说它在看接触。
   良性平移 0.54 / 0.46，说明它不是单纯的位移检测器。检出较好的是 scale_down 0.88（但该类涂抹量 0.71，与 null 不匹配，
   可能仍含涂抹因素）、color_cast 0.77、halo 0.76、no_shadow 0.71。
2. **A4（"通用 reward 看不出物理错误"）依然不成立**，但表述要改成：它对光照色偏、白边、阴影缺失有中等检出，
   对接触（悬空 / 下沉）没有可靠检出。
3. **我们的 critics：只有为之设计的两类明显优于 EditReward**：light_harmony 对 color_cast 1.00 vs 0.77 [.69,.90]；
   halo critic 对 halo 0.97 [.90,1.00] vs 0.76 [.62,.89]。**注意这两类违例就是照着这两个 critic 的度量造的**
   （color_cast 是 Lab b +25 的整体偏色，halo 是膨胀 mask 粘贴），所以 1.00 / 0.97 有近乎"按构造成立"的成分，不能当成泛化能力。
4. **`appearance` / `texture` 对平移也是 1.00（benign 1.00）**：它们是"任何几何或位置改变"检测器，不是物理判断。
   `unchanged_bg` 方向相反（detect 0.16–0.40，contrast 0.74–0.77），在惩罚被平移露出的涂抹区域，探索性，不用。
5. **接触和阴影仍然没有可用 critic。**
   - 悬空：support 0.77 [.55,.94]、vlm_support 0.82 [.66,.94]、vlm_surface 0.82 [.66,.94] 的 contrast 下界 >0.5，
     比 EditReward 的 0.63 [.46,.79] 点估计高，但 CI 重叠。
   - 下沉：没有任何模型检出；vlm_surface 0.23 [.11,.40]、vlm_support 0.30 [.16,.42] 反向（把下沉打得更高）。
   - 阴影缺失：最好是 EditReward 0.71 [.61,.84]，vlm_support / vlm_surface 0.66；vlm_shadow 0.51、contact_shadow 0.52。
   - 这些 VLM 问题在 vlmvar 里对措辞很敏感（support 47/90、surface 52/90 的逐任务胜负稳定），所以上面的 VLM contrast
     数字不一定对改写稳健，没有用多种措辞复测。

## 组合（EditReward + critic，z 分数平均，无拟合；探索性，未做多重比较校正）
- 组合基本等于 EditReward 加上该 critic 擅长的那一类：+light_harmony 把 color_cast 提到 1.00；+halo 0.96 [.87,1.00]；
  +texture 把 scale_up / scale_down 提到 0.99 / 1.00。这是"专用检测器补通用 reward"，不是新的物理能力。
- +vlm_support / vlm_surface：float contrast 0.78 / 0.82（EditReward 0.63），但 sink 掉到 0.32 / 0.35，因为这两个 critic 在 sink 上反向。
- 挑最好的组合报告属于事后挑选；论文里只能报告"预先指定的组合"全集。

## 局限
15 张源图、CI 宽；约 11 列 × 30 个模型没有多重比较校正；违例都是我们合成的；指令是通用的；scale_* 的涂抹量未匹配；
主体旁的投影未随平移移动；没有人工判断来证明违例集分数与人的感觉一致（已决定不做标注）。

Findings
* Heuristic critics are **sharp but narrow** (support→floating 0.85, light_harmony→colour cast 1.00, halo→halo 0.97);
  VLM critics are **broad but weaker** (0.6–0.88 across several violation types). Combined they cover more.
* **Missing contact shadows are invisible to every critic** (heuristic 0.33, VLM 0.40). **Sinking (6 % of height)
  is invisible too.** Both are honest negative results — shadow physics needs a dedicated model.
* The confound was real: on untouched photos the VLM answers 0.88–0.98, on the null paste 0.73–0.97 — the VLM
  noticed the inpainting / paste artefacts. v1's "real vs violation" AUROCs overstated every critic.

## 3. Re-scoring the finished runs with critics v2

| | ip2p v1 → v2 | comp v1 → v2 |
|---|---|---|
| gate passed | 79 → 63 (→ 55 with the semantic gate) | 90 → 90 |
| median overall | 0.672 → 0.669 | 0.913 → 0.949 (0.879 with world softmin) |
| appearance median | 0.33 → 0.56 | 0.57 → **1.00** (pixel-exact pastes no longer "drift") |
| comp > ip2p | | **90 / 90** |

* The alignment fix works: compositing keeps the subject pixel-exact and now scores appearance ≈ 1.0,
  silhouette 0.97.
* Restyles are now gated: e.g. ip2p "forest" = green tint 0.69 → 0, "snow" = cooler colours 0.68 → 0.
* **Remaining leak:** heavy recolouring also moves DINOv2 features, so a few restyles passed `bg_changed`
  (e.g. 0.08 → 0.45). Fix (this commit): `bg_semantic` is catastrophic when SigLIP still ranks the SOURCE scene
  first (unless the target may contain it) — gates 8 more ip2p tasks, no comp task.
* **Saturation:** comp's median 0.95 leaves little room for the loop. Averaging 7 world checks hides single
  physical errors (the tent-hugging case scores 0.90 with vlm_integration 0.59, vlm_shadow 0.33).
  Fix (this commit): world branch = mean of its 2 weakest checks (`branch_reduce.world: softmin2`) → comp median 0.88.

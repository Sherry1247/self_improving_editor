# 接触（悬空 / 下沉）诊断：support 为什么对下沉无效（2026-11-06）

数据：CHTC `contactdiag`（`experiments/support_diagnostics.py`，15 张源图，深度 + SAM2，无 VLM），比较表 `runs/contactdiag_cmp/compare.md`。
图：`docs/img/contact_fig1_matched_controls.png`。AUROC [95% CI，按源图 bootstrap]。

## 发现
1. **下沉在深度特征上几乎没有变化**（和良性平移一样，≈0）。深度网络把下沉 6% 的主体读成"站得稍近一点"，
   所以任何基于深度的接触检测器都看不到它。这很可能不是 `support` 的 bug：把整个主体在图里整体下移而不缩放，
   在单张图里本身就能被解释成"离相机更近"，违例定义有歧义；真正的"陷进地面"（脚被地面遮住一部分）我们没有构造。
2. **悬空（上移 10%）能检出：** 平面残差 `contact_dres` detect 0.80 [.64,.94]，对照（悬空 vs 平移）0.81 [.62,.96]，
   良性平移 0.50 [.34,.65] / 0.48 [.32,.65]。现有 `support` 是 0.66 / 0.77 [.55,.94] / 0.37 / 0.32（良性反向）。
   即：新的残差版本把良性平移校准到 0.5，点估计更高，但对照的 CI 与旧版重叠，不能说显著更好。
3. **"反向"的主要原因很可能是构造造成的残差混杂：** 为了做良性对照，`shift_side` 把脚下一条真实地面一起平移；而所有变体共用的补背景
   区域包含了下沉 / 悬空会占到的位置，使 **null 在脚下那一条地面是被修补过的**，shift_side 反而更干净。结果带符号间隙类特征
   （contact_dsgap）上 null 比平移"更差"：benign 0.21 [.06,.40]、0.19 [.05,.35]，显著低于 0.5。这不是物理判断。
4. **no_shadow 被 `contact_dres` 检出（0.79 [.67,.92]）也要小心：** no_shadow 变体脚下有一块额外的补背景（为了去掉阴影），
   深度在那里变了。阴影缺失和"脚下被修补过的纹理"在这个变体里分不开，EditReward 的 0.71 也有同样的问题。

## 结论（能说的）
- 悬空：有一个较好的、无需 VLM 的检测（平面残差），对良性平移不乱报；样本只有 15 张图。
- 下沉：这套违例里没有任何模型能检出，原因更可能是违例定义（整体下移 = 站近一点）而不是检测器差。
- 阴影缺失：目前无法与补背景纹理区分。

## 局限与待办

- 违例集还要修：null 脚下的修补痕迹、真正的"陷入地面"变体、阴影缺失变体的补背景混杂。

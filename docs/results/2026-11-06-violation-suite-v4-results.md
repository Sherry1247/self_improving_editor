# 违例集 v4 的结果：接触、阴影，以及冻结判据的结论（2026-11-06）

数据：CHTC `e1v4`（critics）、`cdiag4`（接触候选）、`rw_v4_er`（EditReward）；195 项 = 15 张源图 × 13 种变体。
表：CHTC `runs/vio4/compare.md`、`runs/cdiag4_cmp/compare.md`。图：`docs/img/contact_fig2_v4_matched_controls.png`。
AUROC [95% CI，按 15 张源图 cluster bootstrap]。判据在看结果前写下：`docs/specs/2026-11-06-contact-detector-freeze.md`。

## v4 相对 v3 改了什么
脚下地面在所有变体里都不被修补（平移变体让地面和接触阴影一起移动）；新增 `buried`（脚被地面遮住）、`smear_ctrl`（与缩小等量的
修补暴露，用腐蚀边缘做）；`no_shadow` 改成"提亮脚下偏暗的低频成分、不修补"。涂抹量（可见修补面积 / 主体面积）：
null / float / no_shadow 0.69，sink 0.73，shift_side 0.76 / 0.73，buried 0.78，scale_up 0.47，scale_down 1.20，smear_ctrl 1.29。

## 2. v3 里 support 反向，主要是违例集造成的
同一份 `support`（SupportCritic）代码：良性平移 0.37 / 0.32（v3）→ **0.50 [.35,.65] / 0.46 [.32,.59]**（v4）；悬空对照 0.77 → **0.84 [.66,.98]**；
悬空检出 0.66 → 0.85 [.66,.99]。把脚下地面的修补混杂去掉后，现有 critic 就能把悬空和平移分开。三个候选（dgap 0.93、dsgap 0.96、dres 0.80）与
support_v0 的对照 CI 互相重叠，没有证据说它们更好；它们里面 dgap / dsgap 点估计更高，但这是在看过结果后的挑选（赢家诅咒），不作主张。

- EditReward 能检出悬空（0.81），但**对平移也有反应**（良性 0.64 / 0.59：把干净粘贴打得比平移高），悬空 vs 平移的对照只有 0.60 [0.44,0.75]，
  CI 含 0.5。也就是它能发现"这张图有点不对"，分不开"位置被挪了"和"没有接触"。
- support / vlm_support / vlm_surface 的对照下界都 >0.5（0.84 / 0.82 / 0.77），良性平移约 0.5（vlm_surface 的 0.63 偏高）。
  与 EditReward 的差别在点估计上是 0.17–0.24，但 CI 部分重叠；是否显著，要看配对差检验（`violation_compare.py --diff`，**未预先指定，探索性**）。
- 阴影缺失：EditReward 0.60 [0.50,0.73]（v3 是 0.71），contact_shadow 0.62 [0.50,0.75]，其余都在 0.5 附近；v3 里
  contact_dres 的 0.79、vlm_support / vlm_surface 的 0.66 在 v4 降到 0.43 / 0.52 / 0.48 —— v3 的高分是脚下修补纹理造成的。
- 缩小：EditReward 0.95，但 `smear_ctrl`（等量修补、不缩放）它是 1.00，对照 0.10：它对修补 / 边缘伪影极敏感。`smear_ctrl` 本身把主体边缘腐蚀了，
  是个可见的新违例（appearance、identity、silhouette、vlm_integration、vlm_lighting 对它都 ≈1.0），所以它**不是干净的对照**，不能据此判断缩小的检出是不是涂抹造成的。

## 4. 其他
- 色偏：light_harmony 1.00（EditReward 0.81 [.72,.94]）；白边：halo critic 0.97 [.90,1.00]（EditReward 0.76 [.61,.88]）。这两类违例是照着这两个 critic 造的。
- 埋入：EditReward 0.73、support 0.75 [.59,.90]、silhouette 0.92（脚被切掉，剪影变了），不能说明接触检测有效。
- 下沉：所有模型 ≈0.5；v3 的深度特征没有变化，下沉与"站得更近"有歧义，不当作接触违例。
- appearance / texture：对良性平移也是 1.00，是"任何改变"检测器。unchanged_bg：良性平移 0.08 / 0.11，方向反了（惩罚被平移露出的修补区域）。

## 论文里能写的
- 受控违例集要有匹配对照；v3 → v4 的对比本身就是证据：同一个 support critic，良性平移从反向 0.37 / 0.32 回到 0.50 / 0.46。
- 通用奖励模型对多种违例有中等检出，但悬空 vs 平移的区分没有显著证据；接触专用 critic（深度间隙、VLM 的支撑 / 表面问题）有。
- 阴影缺失在去掉修补混杂后，EditReward 和我们的 critic 都只是在 0.5 的边缘。
## 局限
15 张源图；合成违例；同一批源图复现，不是留出（见 spec）；smear_ctrl 不是干净对照；VLM critic 对措辞敏感（vlmvar），vlm_support / vlm_surface 的结果未做措辞复测；约 14 列 × 30 模型未校正多重比较。
